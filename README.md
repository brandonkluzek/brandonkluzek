# Hi, I’m Brandon 👋

I build experiments and software for understanding how AI systems reason—and for checking whether an apparent improvement is real.

My background is in engineering physics and production data systems, which probably explains why I enjoy both abstract questions and stubborn implementation details. Much of my work begins with a fuzzy question and turns it into something inspectable: a frozen task, a clear grader, a replayable run, or a failure case we can learn from.

Right now, I’m especially interested in model behavior, reasoning evaluation, verifiable feedback, and the path from a working prototype to evidence somebody else can reproduce. Longer term, I want to help build AI systems that can contribute reliably to difficult work in mathematics and physics.

## What I work on

- **Reasoning evaluation** — separating failures in representation, instruction-following, legal or valid action, correctness, strategy, and multi-step execution.
- **Verifiable feedback** — designing tasks and reward signals where success can be checked independently, then evaluating interventions against held-out evidence.
- **Research systems** — building datasets, graders, command-line tools, run records, and replay systems that make experiments easier to audit and repeat.
- **Structured testbeds** — using chess, learning systems, and finite games as different laboratories for studying AI behavior.

## What connects the work

Each project asks a version of the same question:

**How do we turn behavior that looks intelligent into something we can define, measure, challenge, and improve?**

I’m interested in building the pieces that make serious answers possible: clear tasks, trustworthy graders, controlled experiments, replayable evidence, and useful failure analysis.
